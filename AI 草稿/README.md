# AI 草稿

> 本说明由 AI 按《笔记库优化方案》生成。

这里存放 AI 新生成或整理后等待确认的内容。

## 写入规则

1. AI 生成的内容必须明确标记。
2. 未确认内容不能写成已经验证的事实。
3. 修改正式笔记前，先展示差异或修改摘要。
4. 删除、移动和批量修改必须单独确认。
5. 用户确认后，再将草稿移入正式目录。
