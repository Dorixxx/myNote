# 上线文档

关联需求：[[取件地址类型与邮寄状态兼容需求]]

## 1. 上线内容

- 邮寄配置增加取件地址类型 `pickup_address`。
- 库存校验切换为批量接口，并传递取件库房编码。
- 小邮局下单增加 `takeAddressType`。
- 兼容小邮局“已退单”和“已打包”状态。
- 已上线裂变活动统一调整为：
  - 取件库房：顺丰库房，编码 `3`。
  - 快递方式：顺丰小件电商，编码 `7`。

## 4. 数据库脚本

数据库：`fundx_equitycenter`

### 4.1 DDL

先通过 `information_schema.COLUMNS` 确认字段是否存在；已存在时不要重复执行对应 `ALTER TABLE`。

```sql
SELECT TABLE_NAME,
       COLUMN_NAME,
       COLUMN_TYPE,
       IS_NULLABLE,
       COLUMN_DEFAULT
FROM information_schema.COLUMNS
WHERE TABLE_SCHEMA = 'fundx_equitycenter'
  AND TABLE_NAME IN ('activity_send_info', 'activity_mail_config_info')
  AND COLUMN_NAME = 'pickup_address';
```

字段不存在时执行：

```sql
ALTER TABLE fundx_equitycenter.activity_send_info
    ADD COLUMN pickup_address INT NULL COMMENT '取件地址类型';

ALTER TABLE fundx_equitycenter.activity_mail_config_info
    ADD COLUMN pickup_address TINYINT NULL COMMENT '取件地址类型'
    AFTER sender_address;
```

### 4.2 备份已上线裂变活动邮寄配置

`activity_info.status = 2` 表示物理状态为已上线，`activity_type = 1` 表示裂变活动。

备份表只能创建一次；如已存在，需要更换表名后再执行。

```sql
CREATE TABLE fundx_equitycenter.bak_activity_mail_config_mail_address_20260806
LIKE fundx_equitycenter.activity_mail_config_info;

INSERT INTO fundx_equitycenter.bak_activity_mail_config_mail_address_20260806
SELECT DISTINCT mc.*
FROM fundx_equitycenter.activity_info ai
JOIN fundx_equitycenter.activity_mail_mapping_info mm
  ON mm.activity_code = ai.activity_code
JOIN fundx_equitycenter.activity_mail_config_info mc
  ON mc.mail_config_code = mm.mail_config_code
WHERE ai.activity_type = 1
  AND ai.status = 2;
```

### 4.3 更新已上线裂变活动

统一设置为顺丰库房（`pickup_address = 3`）和顺丰小件电商（`express_type = 7`）。

```sql
START TRANSACTION;

UPDATE fundx_equitycenter.activity_mail_config_info mc
JOIN fundx_equitycenter.activity_mail_mapping_info mm
  ON mm.mail_config_code = mc.mail_config_code
JOIN fundx_equitycenter.activity_info ai
  ON ai.activity_code = mm.activity_code
SET mc.pickup_address = 3,
    mc.express_type = 7
WHERE ai.activity_type = 1
  AND ai.status = 2;

COMMIT;
```

## 5. 上线顺序

1. 发布雪源商品库存服务，确保批量库存接口可用。
2. 发布小邮局 Proto 和小邮局 gRPC 服务。
3. 暂停 `fissionMailConfigHandleJob`。
4. 执行数据库 DDL。
5. 执行裂变活动配置备份及数据更新 SQL。
6. 发布 `fundx-equity-center-xy` 的 `server`、`admin`。
7. 发布 `fundx-equity-center` 的 `server`、`admin`。
8. 恢复 `fissionMailConfigHandleJob`。

## 6. 回滚

应用回滚到发布前版本。数据库新增字段保留，不执行删列。

恢复本次修改的裂变活动邮寄配置：

```sql
START TRANSACTION;

UPDATE fundx_equitycenter.activity_mail_config_info mc
JOIN fundx_equitycenter.bak_activity_mail_config_mail_address_20260806 bak
  ON bak.id = mc.id
SET mc.pickup_address = bak.pickup_address,
    mc.express_type = bak.express_type,
    mc.update_by = bak.update_by,
    mc.update_time = bak.update_time,
    mc.version = bak.version;

COMMIT;
```

回滚期间保持 `fissionMailConfigHandleJob` 暂停，应用和数据恢复完成后再恢复任务。
